# Q1.Connect a USB webcam to your computer, install any required drivers, and verify that the webcam works by opening the default camera app and capturing a photo.
Ans>
## 📷 USB Webcam Setup and Testing

### Procedure

1. **Connect the Webcam:** Plug the USB webcam into an available USB port on the computer.

2. **Install Drivers:** Allow Windows to detect the webcam and install the required drivers automatically. If necessary, download the driver from the manufacturer's official website.

3. **Open the Camera App:** Click **Start → Camera** to open the Windows Camera application.

4. **Check the Webcam:** Verify that the webcam displays a live video feed on the screen.

5. **Allow Camera Access:** If the webcam does not work, go to **Settings → Privacy → Camera** and enable camera access.

6. **Capture a Photo:** Click the camera button in the Camera app to capture a photo.

7. **Verify the Photo:** Open the saved photo to confirm that the webcam is working correctly.

### Expected Result

The USB webcam is successfully connected, displays live video, and captures and saves a photo.
# Q2.Set up a local printer (USB or network), install the correct driver, and print a test page to confirm successful installation.
Ans>
## 🖨️ Printer Setup and Test Printing

### Procedure

1. **Connect the Printer:** Connect the printer to the computer using a USB cable, or connect both devices to the same Wi-Fi network.

2. **Power On:** Switch on the printer and ensure it has sufficient paper and ink or toner.

3. **Install the Driver:** Download and install the correct printer driver from the manufacturer's official website, if required.

4. **Add the Printer:** Open **Settings → Devices → Printers & scanners** in Windows 10 and click **Add a printer or scanner**.

5. **Select the Printer:** Choose the detected printer from the list and follow the on-screen instructions to complete installation.

6. **Print a Test Page:** Open **Control Panel → Devices and Printers**, right-click the installed printer, select **Printer properties**, and click **Print Test Page**.

7. **Verify the Result:** Check that the test page prints correctly and that the printer is not showing an offline or error status.

### Expected Result

The printer is successfully connected, the correct driver is installed, and the test page prints successfully.
# Q3.Simulate a connectivity issue by unplugging the printer's USB cable, then use Windows Device Manager to identify and resolve the 'printer not detected' problem.<br><br><em><strong>Hint:</strong> Check for error icons and use the 'Scan for hardware changes' option after reconnecting.</em>
Ans>
## 🖨️ Troubleshooting: Printer Not Detected in Windows

### Procedure

1. **Simulate the Issue:** Disconnect the printer's USB cable from the computer to simulate a connectivity problem.

2. **Open Device Manager:** Right-click the Start button and select **Device Manager**.

3. **Check for Errors:** Expand **Printers**, **Print queues**, and **Universal Serial Bus controllers**. Look for yellow warning icons or devices that are missing or listed as unknown devices.

4. **Reconnect the Printer:** Plug the USB cable back into the computer and ensure the printer is switched on.

5. **Scan for Hardware Changes:** In Device Manager, click **Action → Scan for hardware changes** to make Windows detect the connected printer again.

6. **Update the Driver:** If the printer still has a warning icon, right-click the device and select **Update driver**. Install the correct driver from the manufacturer's official website if necessary.

7. **Verify the Connection:** Open **Settings → Devices → Printers & scanners** and check whether the printer appears in the list.

8. **Test the Printer:** Print a test page to confirm that the printer is detected and working correctly.

### Expected Result

Windows detects the printer after the USB cable is reconnected and the hardware scan is completed. Any driver issues are addressed, and the printer is ready to use.

### Conclusion

Device Manager helps identify hardware detection and driver problems. Reconnecting the USB cable, scanning for hardware changes, and updating the driver can resolve common printer connectivity issues.
# Q4.A user reports that their webcam video is not displaying in Zoom, but it works in the default camera app. Troubleshoot and resolve the issue so the webcam works in both applications.<br><br><em><strong>Hint:</strong> Check if another app is using the webcam or if Zoom permissions are enabled.</em>
Ans>
## 📷 Troubleshooting: Webcam Not Working in Zoom

### Procedure

1. **Verify the Webcam:** Open the default Windows Camera app and confirm that the webcam displays video correctly.

2. **Close Other Applications:** Close the Camera app and any other applications that may be using the webcam.

3. **Check Camera Permissions:** Go to **Settings → Privacy → Camera** in Windows 10. Enable camera access and allow desktop apps to access the camera.

4. **Check Zoom Settings:** Open Zoom and navigate to **Settings → Video**. Select the correct webcam from the Camera dropdown menu.

5. **Check Zoom Permissions:** Ensure Zoom is allowed to access the webcam. If necessary, restart Zoom after changing the permissions.

6. **Restart Zoom:** Completely close Zoom, reopen it, and test the webcam again.

7. **Update Zoom:** Install the latest available version of Zoom if the issue persists.

8. **Test the Webcam:** Start a Zoom test meeting and verify that the video appears correctly.

### Expected Result

The webcam displays video in both the Windows Camera app and Zoom after the correct camera is selected, permissions are enabled, and conflicting applications are closed.

### Conclusion

If a webcam works in the default Camera app but not in Zoom, the problem is often related to camera permissions, incorrect device selection, or another application using the webcam.
